# Two Pointers

## Overview
The two pointers technique uses two indices to traverse an array or sequence, often from opposite ends or both moving forward.

## When to Use
- Sorted arrays where you need to find pairs or triplets.
- Problems involving partitioning or merging.
- Palindrome checks and sliding window variations.

## Common Patterns
- **Opposite ends**: One pointer at start, one at end, move toward each other.
- **Same direction**: Both pointers move forward at different speeds.
- **Fast/slow**: Detect cycles or find middle elements.

## Common Mistakes
- Moving both pointers at the wrong time.
- Missing the case where pointers cross.
- Not handling duplicate values in sorted arrays.
